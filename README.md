# Centro de Mando de Inversiones PRO (Hapi & Ecosistema Google)

Terminal financiera interactiva y automatizada para monitoreo del portafolio real en Hapi ($25 USD/mes) y capacitación diaria de inversiones.

## 🚀 Despliegue en GitHub Pages (100% Gratuito y Dinámico)

Este proyecto funciona como una Single Page Application (SPA) ultra ligera con Tailwind CSS y Chart.js vía CDN. Se conecta de forma dinámica y automática a tu hoja de cálculo maestra en Google Drive:
- **ID de la Hoja:** `1cGYgRlmaJ0_IbDHnnDFSF3wQ7e8CF10XPU4OzKLVHIE`
- **Pestañas vinculadas:** `resumen_portafolio` (TRM y posiciones en vivo) y `bitacora_capacitacion` (lección del día).

### Pasos de Publicación:
1. Sube este archivo `index.html` a la rama `main` de tu repositorio en GitHub.
2. Ve a **Settings > Pages** en tu repositorio.
3. En **Build and deployment > Branch**, selecciona `main` y la carpeta `/ (root)`. Haz clic en **Save**.
4. En 1 minuto tendrás tu URL pública: `https://<tu-usuario>.github.io/<tu-repositorio>/`.
5. En Google Sites, ve a **Insertar > Por URL** y pega tu enlace de GitHub Pages.
